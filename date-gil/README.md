# 데이트길잡이 💑

두 사람의 성향·취향·상황을 합쳐 맞춤 데이트 코스를 짜주는 모바일 웹앱 (PWA, 설치 가능)

## 실행
- 같은 와이파이에서 테스트: 이 폴더에서 `python -m http.server 8000` → 휴대폰에서 `http://<PC IP>:8000`
- 실제 사용/공유: 이 폴더를 HTTPS로 호스팅 (GitHub Pages, Netlify Drop 등) → "홈 화면에 추가"
  - 초대/공유/투표/서프라이즈 링크는 호스팅된 주소여야 상대 폰에서 열려요 (`file://` 불가)
- 테스트: `node tests/engine.test.js`

## 카카오 키 설정 (실제 장소 추천)
키가 없으면 **데모 모드**로 동작해요 (예시 장소, "예시" 배지 표시).
1. https://developers.kakao.com → 애플리케이션 추가 → **JavaScript 키** 복사
2. 앱 설정 → 플랫폼 → Web → 사이트 도메인에 호스팅 주소 등록 (예: `https://xxx.netlify.app`)
3. 제품 설정에서 카카오맵 사용 활성화
4. 앱 ⚙️ 설정 → 카카오 JavaScript 키 입력
→ 실제 장소 검색(카카오 로컬), 지도 동선 표시, 카카오톡 공유가 켜져요.

## 기능
- **커플 프로필**: MBTI, 데이트 성향(복수), 알러지, 싫어하는/좋아하는 음식, 맵기, 음주 · 기념일, 교통수단, 예산
- **연결**: 초대 링크/코드를 주고받아 연결 (서버 없음, 코드에 프로필이 담겨 있음)
- **코스 생성**: 지역 직접 입력 또는 AI 지역 추천(컨셉×성향×교통수단 점수, 추천 이유 포함) → 날짜·시간대 → 컨셉·예산 → 식당/카페 옵션, 놀거리, 필터
- **추천 로직** (`js/engine.js`)
  - 카테고리·장소명 → 주메뉴 재료 태깅 → 한 명이라도 알러지면 **제외**, 싫어하는 재료는 감점, 맵기·음주 반영
  - 두 사람 만족도의 **최솟값**을 우선해 점수화 → 한쪽만 좋은 곳보다 둘 다 괜찮은 곳 우선, 놀거리 유형도 둘의 성향이 고르게 들어가게 배치
  - 빔 서치로 점수 − 이동시간 − 예산 초과 − 메뉴 중복을 최적화 (동선 최적화)
  - 날씨(Open-Meteo): 비 예보면 실내 위주 플랜B 자동 생성, 언제든 플랜B 수동 생성 가능
  - 이미 가본 곳 제외, 과거 장소 별점·비슷한 스타일 별점 반영
- **결과**: 타임라인(시간·장소·추천 이유·예상 비용·이동시간), 지도 동선, 장소별 다시 추천, 지도/길찾기/예약 링크, 알러지 안내 문구
- **부가**: 연인 투표(👍/👎 → 내 코스에 반영), 서프라이즈 초대장(시간·만날 장소만 공개), 저장, 카톡 공유, 기념일 2주 전 알림, 별점·한줄후기·사진 데이트 캘린더, 백업/복원

## 한계 (솔직하게)
- **영업시간/휴무일**: 카카오 공식 API는 영업시간을 주지 않아요. 카테고리별 일반적인 영업시간(미술관 월요일 휴무, 브레이크타임 등)으로 추정해 거르고, 화면에 "확인 필요"로 표시해요. 정확히 하려면 영업시간을 주는 API를 서버에서 연동해야 해요.
- **웨이팅/예약 가능 여부**: 카테고리 기반 추정. 주차는 카카오 주차장 검색으로 장소 350m 안에 주차장이 있는지 확인해요.
- **메뉴 성분**: 카테고리 기반이라 완벽하지 않아요 → 앱에서 "방문 전 매장에 확인" 안내.
- **동기화**: 서버가 없어 연결·투표는 링크/코드 교환 방식이고, 데이터는 각 기기에 저장돼요. 실시간 동기화나 푸시 알림(앱을 안 열어도 오는 알림)은 백엔드(예: Firebase)가 필요해요.
- **AI 지역 추천**: 직접 만든 지역 DB(서울·부산 19곳)를 규칙으로 점수화한 것이에요. LLM 연동은 하지 않았어요.

## 구조
- `js/data.js` 선택지 · 장소 태깅 규칙 · 영업시간 규칙 · 지역 DB · 데모 템플릿
- `js/engine.js` 태깅/점수/슬롯/코스 조립/다시 추천/날씨 판정/지역 추천/기념일/공유 코드 (순수 함수)
- `js/sources.js` 카카오·데모 장소 소스, 날씨, 코스 생성 파이프라인
- `js/app.js` UI (해시 라우팅, 탭 선택형 입력)
