# GROW · 근성장 트레이너

헬스장용 루틴 생성 + 자동 점진적 과부하 웹앱 (PWA, 설치 가능, 오프라인 동작)

## 실행
- PC: `index.html` 더블클릭
- 휴대폰 설치: 이 폴더를 HTTPS로 호스팅 (예: GitHub Pages, Netlify Drop) → 휴대폰 브라우저로 접속 → "홈 화면에 추가"
- 같은 와이파이에서 테스트: `python -m http.server 8000` → 휴대폰에서 `http://<PC IP>:8000`

## 기능
- **운동 기록 + 자동 점진적 과부하**: 운동 시작 → 종목 검색해서 추가 → 추가 즉시 오늘 무게·목표 반복 자동 입력
- **종목 검색 (125종 + 직접 추가)**: 한글/초성(ㅅㅋㅌ)/영문/별칭(사레레, 랫풀) 검색, 부위·장비 필터, 최근·자주 한 종목 우선, 검색 결과에 지난 기록 → 오늘 처방 표시, 없는 종목은 바로 만들어 추가
- **최근 운동 다시 하기**: 지난 세션 구성 그대로, 무게/반복은 새로 처방
- **컨셉 5종** (운동 중 변경 가능): 근성장 / 근력 / 다이어트 / 자극위주 / 펌핑위주
- **점진적 과부하 (더블 프로그레션)**: 모든 세트 상한 달성 → 증량 / 범위 안 → +1회 / 2회 연속 실패 → 10% 디로드 / 21일 공백 → 10% 보정 / 컨셉 변경 시 추정 1RM으로 환산
- 세트별 무게·반복 수정, 휴식 타이머, 워밍업 세트 제안, 종목 교체
- (선택) 자동 루틴 추천: 부위·근육 발달도·회복 상태 기반
- 기록, 종목별 추정 1RM 그래프, 주간 볼륨, 근력 기준 발달도 평가, JSON 백업/복원

## 구조
- `js/data.js` 종목 DB · 컨셉 파라미터 · 근력 기준표
- `js/engine.js` 루틴 생성/과부하 로직 (UI 없는 순수 함수)
- `js/app.js` UI
- 테스트: `node tests/engine.test.js`
